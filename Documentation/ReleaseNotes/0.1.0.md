# CodexMeter 0.1.0

- Adds accurate local Codex token totals for today, this week, this month, and all locally available history.
- Excludes inherited parent history replayed into forked and subagent sessions.
- Starts with a quiet icon-only menu bar item on fresh installs.
- Restores the native Settings window and adds signed automatic updates.

The Universal 2 DMG and ZIP are maintainer-test previews only. They are Apple Development-signed and Sparkle EdDSA-signed for update testing, but they are not Developer ID-signed or notarized by Apple and are not a trusted first-install distribution. Do not bypass Gatekeeper to install them; build from source or wait for a release that passes the public Developer ID and notarization gate.
