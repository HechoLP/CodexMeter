# CodexMeter 0.1.0

- Adds accurate local Codex token totals for today, this week, this month, and all locally available history.
- Excludes inherited parent history replayed into forked and subagent sessions.
- Starts with a quiet icon-only menu bar item on fresh installs.
- Restores the native Settings window and adds signed automatic updates.

The Universal 2 DMG and ZIP are maintainer-test previews only. They are Apple Development-signed and Sparkle EdDSA-signed for update testing, but they are not Developer ID-signed or notarized by Apple and are not a trusted first-install distribution. Prefer building from source or waiting for a release that passes the public Developer ID and notarization gate.

## macOS에서 처음 실행할 때

공식 GitHub 릴리스에서 `CodexMeter-0.1.0.dmg`와 `SHA256SUMS.txt`를 같은 폴더에 다운로드합니다. 아래 검사가 `OK`를 출력하지 않으면 실행하지 마세요.

```bash
cd ~/Downloads
grep ' CodexMeter-0.1.0.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-0.1.0.dmg
```

DMG에서 `CodexMeter.app`을 `Applications` 폴더로 복사한 뒤, 체크섬이 일치한 공식 프리뷰에 한해서만 실행합니다.

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

이 명령은 해당 앱의 다운로드 격리 속성을 제거합니다. 출처가 다르거나 체크섬이 일치하지 않는 파일에는 사용하지 마세요.
