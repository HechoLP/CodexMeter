# CodexMeter 1.0.1

CodexMeter 1.0.1 fixes the menu-bar text control and makes the scope of lifetime totals explicit.

## Changes

- **Show token text** can now be enabled directly from the default icon-only presentation.
- Menu-bar text content, period, and number format remain available as separate choices once text is enabled.
- The previous **All Time** label is now **Local History** because CodexMeter reads only session records currently present on this computer.
- The activity formula remains `Input + Cached Input + Output`; the local value can be lower than the ChatGPT account total when older logs or activity from another computer are unavailable locally.
- Windows uses the same **Local History** terminology.

## Integrity and platform trust

These packages are distributed without Apple Developer ID, Apple notarization, or a Microsoft publisher certificate. Verify the official SHA-256 manifest before bypassing Gatekeeper or SmartScreen. The macOS automatic-update feed and ZIP archive are separately authenticated with Sparkle Ed25519 signatures.

## macOS with Homebrew

```bash
brew install --cask HechoLP/tap/codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Existing macOS installations can update through CodexMeter's signed update checker after the v1.0.1 feed is published.

## Windows portable download

Download the x64 or ARM64 ZIP together with `SHA256SUMS-windows.txt`, compare the PowerShell `Get-FileHash` result with the manifest, and extract the verified package to a permanent folder.
