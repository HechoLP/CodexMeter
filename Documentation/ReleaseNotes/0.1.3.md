# CodexMeter 0.1.3

- Replaces vague history-quality warnings with concrete refresh results and update timestamps.
- Rotates the refresh control once per refresh and animates changed totals without continuous motion.
- Respects the macOS Reduce Motion accessibility setting.
- Adds installation through the public `HechoLP/homebrew-tap` personal Tap.

This build is ad-hoc signed and is not notarized by Apple. Homebrew verifies the exact published ZIP with SHA-256, but the personal Tap does not make the app Apple-trusted.

## Homebrew

```bash
brew install --cask HechoLP/tap/codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

The `xattr` command removes macOS download quarantine from `CodexMeter.app` only. Run it only after the Homebrew installation completes from `HechoLP/tap/codexmeter`.

## Direct download

Download `CodexMeter-0.1.3.dmg` and `SHA256SUMS.txt` from the official public release into the same folder. Do not continue unless the checksum command prints `OK`.

```bash
cd ~/Downloads
grep ' CodexMeter-0.1.3.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-0.1.3.dmg
```

Copy `CodexMeter.app` from the DMG to `Applications`, then remove quarantine from that app and launch it:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```
