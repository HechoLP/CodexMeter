# CodexMeter 1.1.5

CodexMeter 1.1.5 reorganizes the menu popover into a provider-first vertical layout inspired by the scanability of mature multi-provider menu bar tools while preserving CodexMeter's own identity and data boundaries.

## Easier reading order

- The top of the popover now identifies Codex, its active data scope, and local connection status.
- Account limits appear before token history, with up to three visible windows, reset countdowns, pace, and optional reset-credit context.
- Today's total and its Input, Cached input, and Output breakdown remain together under Token Usage.
- This Week, This Month, and Local History or Lifetime use full-width rows with stable right-aligned values.
- Usage, Projects, and Sessions use larger navigation rows with consistent icons and disclosure indicators.
- Refresh, Settings, and More are visible text actions instead of icon-only controls.

No unsupported Claude, Gemini, or other provider tab is shown. Future providers can join the same structure only after their data and status handling are implemented.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask HechoLP/tap/codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Fresh installations can use `brew install --cask HechoLP/tap/codexmeter`.

## First direct-download launch

The app is ad-hoc signed and not Apple-notarized. Download the DMG and `SHA256SUMS.txt` from the official release, verify the checksum, copy `CodexMeter.app` to Applications, and remove quarantine from this app only:

```bash
cd ~/Downloads
grep ' CodexMeter-1.1.5.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Do not remove quarantine when the checksum does not match the official manifest.
