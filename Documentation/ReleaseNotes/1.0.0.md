# CodexMeter 1.0.0

CodexMeter 1.0.0 is the first stable release for macOS 14+ and Windows 10/11.

## Highlights

- Shows Today, This Week, This Month, and locally observable All Time totals for input, cached input, output, and total activity.
- Matches the ChatGPT profile activity definition: `Input + Cached Input + Output`.
- Starts icon-only, opens a native Settings window reliably, and gives animated feedback while a refresh is running.
- Normalizes cumulative Codex counters without double-counting repeated, archived, forked, inherited, partial, truncated, or rewritten session history.
- Processes only local `.codex` session JSONL files and never stores prompts, responses, source code, credentials, raw session paths, model names, or project paths.
- Provides daily Ed25519-authenticated Sparkle updates on macOS and an explicit GitHub Releases link on Windows.
- Includes Universal 2 macOS ZIP/DMG packages and self-contained Windows x64/ARM64 ZIP packages under one `v1.0.0` release.
- Documents planned future support for Claude and other AI coding assistants while keeping Codex as the first supported source.

## Integrity and platform trust

These stable packages are distributed without Apple Developer ID, Apple notarization, or a Microsoft publisher certificate. Verify the official SHA-256 manifest before bypassing Gatekeeper or SmartScreen. The macOS automatic-update feed and ZIP archive are separately authenticated with Sparkle Ed25519 signatures.

## macOS with Homebrew

```bash
brew install --cask HechoLP/tap/codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Run the `xattr` command only after Homebrew finishes installing `HechoLP/tap/codexmeter`.

## macOS direct download

Download `CodexMeter-1.0.0.dmg` and `SHA256SUMS.txt` from the official release into the same folder. Continue only if verification prints `OK`:

```bash
cd ~/Downloads
grep ' CodexMeter-1.0.0.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-1.0.0.dmg
```

Copy `CodexMeter.app` to Applications, then run the two app-scoped commands shown above.

## Windows portable download

Download the x64 or ARM64 ZIP with `SHA256SUMS-windows.txt`, compare the PowerShell `Get-FileHash` result with the manifest, and extract the verified package to a permanent folder. If Windows marks the file as blocked:

```powershell
Unblock-File .\CodexMeter.exe
Start-Process .\CodexMeter.exe
```
