# CodexMeter 1.1.4

CodexMeter 1.1.4 turns the categorized menu bar overview into a compact, at-a-glance summary.

## Glanceable overview

- Input, Cached input, and Output now appear side by side directly under today's total.
- This Week, This Month, and Local History or Lifetime now appear as a single comparable row.
- The normal popover height shows Local Usage, Account Limits, Token History, and Explore together without unnecessary scrolling.
- Detailed usage, project, session, limit, and period screens remain one click away.
- Long token values scale within their summary cell instead of being cut off.

## Verification

- Complete Swift unit and integration suite: 143 tests passed, with two optional tests skipped
- Native AppKit hosting-size and category-order regression tests
- Impeccable layout detector completed without findings
- Universal 2 architecture, bundle metadata, ad-hoc signature, archive, checksum, and Sparkle feed verification

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask HechoLP/tap/codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Fresh installations can use `brew install --cask HechoLP/tap/codexmeter`.

## First direct-download launch

The app is ad-hoc signed and not Apple-notarized. Download the DMG and `SHA256SUMS.txt` from the official release, verify the checksum, copy `CodexMeter.app` to Applications, and remove quarantine from this app only:

```bash
cd ~/Downloads
grep ' CodexMeter-1.1.4.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Do not remove quarantine when the checksum does not match the official manifest.
