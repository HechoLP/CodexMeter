# CodexMeter 1.4.3

A follow-up to the 1.4.x Settings redesign: the Codex and Claude Code panes now match.

## What changed

- **Consistent provider panes.** Codex's Account section was a plain sentence while Claude's showed an account value and a Disconnect button, and only Claude's header card had a refresh button. Codex's Account section is now the same label/value row as Claude's (showing your saved Codex login, or "Signed in to the Codex app" if none is saved), and Codex's header card has a matching refresh button. Real feature differences stay: Claude keeps its on/off toggle, and the Limits section (additional limits, reset credits) remains Codex-only, since Claude has no equivalent settings.
- **Safer, faster tests.** Settings no longer reads the real Keychain-backed saved-login vault while running automated tests; the account store is injected, with tests using an in-memory one instead.

No preference or behavior changes beyond the above.

## Verification

- 283 automated tests, 0 failures (7 environment-integration tests skipped).
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later; the bundled Claude limits helper is signed and verified as part of the release.
- The app remains ad-hoc signed and not Apple-notarized. SHA-256 protects the first download; Sparkle authenticates later update feeds and archives with Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy HechoLP/tap/codexmeter
```

For a new installation:

```bash
brew install --cask HechoLP/tap/codexmeter
```

If macOS blocks this certificate-free app after installation, confirm that it came from `HechoLP/tap/codexmeter`, then remove quarantine from this app only:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-1.4.3.dmg` and `SHA256SUMS.txt` from this release into the same folder. Verify the checksum before opening the disk image:

```bash
cd ~/Downloads
grep ' CodexMeter-1.4.3.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-1.4.3.dmg
```

Only after the checksum reports `OK`, copy `CodexMeter.app` to Applications and use the app-scoped quarantine command above.
