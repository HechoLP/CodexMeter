# CodexMeter 1.1.1

CodexMeter 1.1.1 makes the project macOS-only so development, testing, documentation, and releases can concentrate on the native menu bar app.

## macOS focus

- Removes the Windows application and its separate .NET implementation from the current source tree.
- Removes Windows build, test, packaging, and release automation.
- Simplifies CI and the stable release gate around the Universal 2 macOS app.
- Updates the product, architecture, privacy, security, installation, and maintainer documentation to describe one supported platform.
- Keeps all existing macOS usage accounting, limits, analytics, settings, launch-at-login, Homebrew, and signed Sparkle update behavior.

Historical tags and changelog entries remain available as an accurate record of previous releases; Windows is no longer part of the supported product or current download path.

## Verification

- Swift unit and integration suite
- Signed local Codex app-server limit integration
- 10,000- and 100,000-event ingestion stress suite
- Universal 2 architecture, bundle metadata, ad-hoc signature, archive, checksum, and Sparkle feed verification

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask HechoLP/tap/codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Fresh installations can use `brew install --cask HechoLP/tap/codexmeter`.

## First direct-download launch

The app is ad-hoc signed and not Apple-notarized. Download the DMG and `SHA256SUMS.txt` from the official release, verify the checksum, copy `CodexMeter.app` to Applications, and remove quarantine from this app only:

```bash
cd ~/Downloads
grep ' CodexMeter-1.1.1.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Do not remove quarantine when the checksum does not match the official manifest.
