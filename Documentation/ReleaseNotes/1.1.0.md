# CodexMeter 1.1.0

CodexMeter 1.1.0 turns the macOS menu popover into a faster, more useful view of live local usage, Codex limits, and private on-device analytics. It also fixes the database-compatibility problem that could make Today suddenly display zero after running a development build.

## macOS highlights

- Keeps this Mac's live Today total and input, cached-input, and output breakdown at the top of the first screen.
- Shows the nearest Codex limit windows, reset countdowns, low-quota warnings, and an explicitly labeled even-use pace estimate.
- Adds Today, 7-day, and 30-day token charts plus model, project, and session drill-down views.
- Adds model-aware API-equivalent cost estimates that are clearly separated from subscription billing.
- Adds quick access to Usage, Projects, Sessions, update checks, the OpenAI status page, GitHub, and Quit.
- Adds fixed 2-, 15-, and 30-minute refresh choices while preserving automatic and manual refresh modes.

## Accuracy and recovery

- Today always uses live local usage rather than a delayed account-profile day.
- Removed the former Profile day row from the primary summary.
- Isolated preview and development data under `CodexMeter-Development`, preventing an unreleased database migration from breaking the installed app's local usage reader.
- Preserved the established Total definition: Input + Output. Cached input remains an auditable subset of Input and is not counted twice.

## Privacy and scope

- Usage analytics stay on this Mac in owner-only local storage.
- Project paths are minimized to keyed identifiers and folder basenames; prompts, responses, source code, terminal output, credentials, and attachment contents are not stored.
- Limit data is read-only and retrieved through the signed local Codex app-server. CodexMeter does not consume reset credits or mutate account settings.
- API-equivalent costs are estimates, not bills or subscription charges.

Windows remains a certificate-free self-contained portable app with the corrected local Total semantics from 1.0.6. The new limits, cost, project, and session analytics in this release are currently macOS-only.

## Integrity and platform trust

These packages are distributed without Apple Developer ID, Apple notarization, or a Microsoft publisher certificate. Verify the official SHA-256 manifest before bypassing Gatekeeper or SmartScreen. The macOS automatic-update feed and ZIP archive are separately authenticated with Sparkle Ed25519 signatures.

## macOS with Homebrew

```bash
brew update
brew upgrade --cask HechoLP/tap/codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Fresh installations can use `brew install --cask HechoLP/tap/codexmeter`.

## Windows portable download

Download the x64 or ARM64 ZIP together with `SHA256SUMS-windows.txt`, compare the PowerShell `Get-FileHash` result with the manifest, and extract the verified package to a permanent folder.
