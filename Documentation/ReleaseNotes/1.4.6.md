# CodexMeter 1.4.6

A bug-fix release for Codex account switching.

## What changed

- **Account switching no longer gets stuck behind unrelated Codex processes.** Modern Codex keeps an idle background app-server running after its window closes, and editor extensions and remote sessions start their own `codex` processes. The previous safety gate blocked a switch whenever any `codex`-named process was alive anywhere on the machine, so the switch would quit and reopen the desktop app but never apply the saved login — leaving only a small "Another Codex process is still running" note under the account menu.
- The gate still identifies Codex processes the same way, but now blocks a switch **only** while one actually holds `~/.codex/auth.json` open, matched by device and inode. An idle daemon, a remote session, or an editor extension that has already released the file no longer blocks. `CodexLoginFile.replace` keeps its compare-and-swap, so a login that changes under the switch is still never overwritten.
- The blocked-state message now points at CLI sessions and editor extensions rather than a generic "close it" instruction.

Switching applies the saved login to Codex (the CLI and the desktop app's Codex side). It does not change the account shown in the ChatGPT desktop app's own chat UI, which authenticates from a separate web session.

## Verification

- 289 automated tests, 0 failures (7 environment-integration tests skipped).
- `swift build` with zero warnings and zero errors.
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later; the bundled Claude limits helper is signed and verified as part of the release.
- Read-only real-desktop probe: three live `codex` processes identified, none holding the login file open, switch no longer blocked.
- The app remains ad-hoc signed and not Apple-notarized. SHA-256 protects the first download; Sparkle authenticates later update feeds and archives with Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy HechoLP/tap/codexmeter
```

For a new installation:

```bash
brew install --cask HechoLP/tap/codexmeter
```

If macOS blocks this certificate-free app after installation, confirm that it came from `HechoLP/tap/codexmeter`, then remove quarantine from this app only:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-1.4.6.dmg` and `SHA256SUMS.txt` from this release into the same folder. Verify the checksum before opening the disk image:

```bash
cd ~/Downloads
grep ' CodexMeter-1.4.6.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-1.4.6.dmg
```

Only after the checksum reports `OK`, copy `CodexMeter.app` to Applications and use the app-scoped quarantine command above.
