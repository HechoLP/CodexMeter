# CodexMeter 1.1.2

CodexMeter 1.1.2 fixes a menu bar layout regression that could hide the entire usage body and leave only the title and footer visible.

## Fixed

- Keeps the scrollable usage and limit body at a usable height whenever the menu bar popover opens or reopens.
- Adds a macOS layout regression test that verifies the popover cannot shrink to the header-and-footer-only state.
- Preserves all existing usage data and accounting behavior; the issue affected presentation only.

## Verification

- Complete Swift unit and integration suite
- Native AppKit hosting-size regression test
- Signed local Codex app-server limit integration
- 10,000- and 100,000-event ingestion stress suite
- Universal 2 architecture, bundle metadata, ad-hoc signature, archive, checksum, and Sparkle feed verification

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask HechoLP/tap/codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Fresh installations can use `brew install --cask HechoLP/tap/codexmeter`.

## First direct-download launch

The app is ad-hoc signed and not Apple-notarized. Download the DMG and `SHA256SUMS.txt` from the official release, verify the checksum, copy `CodexMeter.app` to Applications, and remove quarantine from this app only:

```bash
cd ~/Downloads
grep ' CodexMeter-1.1.2.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Do not remove quarantine when the checksum does not match the official manifest.
