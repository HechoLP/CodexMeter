# CodexMeter 1.0.4

CodexMeter 1.0.4 consolidates the public downloads and signed macOS update feed into the main `HechoLP/CodexMeter` repository.

## Changes

- macOS and Windows downloads now live on the same repository as the source and immutable release tag.
- The macOS app now checks the signed `HechoLP/CodexMeter` update feed.
- Release links in both applications and the installation documentation now open the consolidated release page.
- The personal Homebrew Tap remains separate because Homebrew discovers `HechoLP/tap` through the `HechoLP/homebrew-tap` repository, but its Cask downloads the ZIP from the main repository.

The 1.0.4 feed is also published once to the legacy `CodexMeter-Releases` update branch so installations through 1.0.3 can upgrade safely. The legacy repository remains public and read-only after that bridge; it is not used for later releases.

## Integrity and platform trust

These packages are distributed without Apple Developer ID, Apple notarization, or a Microsoft publisher certificate. Verify the official SHA-256 manifest before bypassing Gatekeeper or SmartScreen. The macOS automatic-update feed and ZIP archive are separately authenticated with Sparkle Ed25519 signatures.

## macOS with Homebrew

```bash
brew update
brew upgrade --cask codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Fresh installations can use `brew install --cask HechoLP/tap/codexmeter`.

## Windows portable download

Download the x64 or ARM64 ZIP together with `SHA256SUMS-windows.txt`, compare the PowerShell `Get-FileHash` result with the manifest, and extract the verified package to a permanent folder.
