# CodexMeter 1.0.3

CodexMeter 1.0.3 fixes the mismatch between this Mac's available session history and the account-wide totals shown by the ChatGPT profile.

## Changes

- macOS can now explicitly enable **Use ChatGPT account totals** in **Settings → Usage & Privacy**.
- The popover clearly separates dated ChatGPT account totals from the **This Mac** input, cached-input, and output breakdown.
- The server's exact snapshot date is always shown because account statistics can lag behind live local activity.
- Opt-in and week-start changes refresh immediately. Local midnight, wake, clock, and time-zone changes invalidate the old calendar period before requesting the new one. Opt-out cancels automatic work and removes the in-memory account snapshot.
- Credential and profile responses are not stored in SQLite, UserDefaults, Keychain, or diagnostics. The local database remains only an incremental cache for auditable local session history.
- Windows remains local-only in this release.

The account view uses a non-public ChatGPT endpoint and may require a CodexMeter update if that endpoint changes. Local accounting continues to work independently.

## Integrity and platform trust

These packages are distributed without Apple Developer ID, Apple notarization, or a Microsoft publisher certificate. Verify the official SHA-256 manifest before bypassing Gatekeeper or SmartScreen. The macOS automatic-update feed and ZIP archive are separately authenticated with Sparkle Ed25519 signatures.

## macOS with Homebrew

```bash
brew update
brew upgrade --cask codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Fresh installations can use `brew install --cask HechoLP/tap/codexmeter`. Existing macOS installations can also update through CodexMeter's signed update checker after the v1.0.3 feed is published.

## Windows portable download

Download the x64 or ARM64 ZIP together with `SHA256SUMS-windows.txt`, compare the PowerShell `Get-FileHash` result with the manifest, and extract the verified package to a permanent folder.
