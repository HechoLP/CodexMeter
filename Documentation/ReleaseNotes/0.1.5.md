# CodexMeter 0.1.5

- Fixes inflated **All Time** totals caused by copied parent token history in inherited Codex sessions.
- Rebuilds the local derived statistics once after updating, while preserving Codex source logs, CodexMeter settings, and any local-history cutoff.
- Builds the release executable in a fresh Swift scratch directory and verifies that the packaged Universal 2 binary contains the accounting migration.

Version 0.1.4 was withdrawn after its package was found to contain a stale executable from the previous build cache. Version 0.1.5 is a clean rebuild from the corrected source and is the supported replacement.

The first refresh after updating may take longer while CodexMeter safely reconstructs its local statistics. No prompt, response, source-code, or credential content is imported into the database.

This build is ad-hoc signed and is not notarized by Apple. Homebrew verifies the exact published ZIP with SHA-256, but the personal Tap does not make the app Apple-trusted.

## Homebrew

```bash
brew upgrade --cask HechoLP/tap/codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

The `xattr` command removes macOS download quarantine from `CodexMeter.app` only. Run it only after the Homebrew installation completes from `HechoLP/tap/codexmeter`.

## Direct download

Download `CodexMeter-0.1.5.dmg` and `SHA256SUMS.txt` from the official public release into the same folder. Do not continue unless the checksum command prints `OK`.

```bash
cd ~/Downloads
grep ' CodexMeter-0.1.5.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-0.1.5.dmg
```

Copy `CodexMeter.app` from the DMG to `Applications`, then remove quarantine from that app and launch it:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```
