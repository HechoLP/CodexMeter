# CodexMeter 1.3.0-beta.2 — Claude Code UI 개선 테스트

macOS 14 이상에서 실행하는 Apple Silicon / Intel 공용 테스트 릴리스입니다. 정식 버전은 v1.2.0으로 유지하며, 이 베타를 Homebrew 또는 자동 업데이트 피드로 배포하지 않습니다.

## beta.2 변경 내용

- Codex와 Claude Code를 더 빠르게 구분할 수 있도록 메뉴 상단을 로고 우선의 제공자 탭으로 바꿨습니다.
- 각 탭의 로고를 이름 위에 배치하고 크기와 간격을 줄여 작은 메뉴에서도 한눈에 보이도록 다듬었습니다.
- 반복되던 CodexMeter 로고와 제목을 메뉴 본문에서 제거해 실제 사용량과 한도 정보가 먼저 보이도록 했습니다.
- 호스팅된 UI 검사에서 글리프 인식 차이로 발생하던 잘못된 실패를 보정했습니다.

beta.1에서 추가한 Claude Code 로컬 토큰 사용량, 모델·프로젝트·세션 분석, 응답 중복 제거와 새로 고침 동기화 기능은 그대로 포함합니다.

Claude 지원 범위는 이 Mac의 Claude Code 로컬 기록입니다. Claude 웹·모바일·다른 기기의 사용량, 계정 한도·전환, 비용 추정은 이번 베타에 포함되지 않습니다. 기본 읽기 경로는 `~/.claude/projects`이며 Claude 로그인이나 API 키 연결은 필요하지 않습니다.

## 설치 및 테스트

1. 아래 릴리스 자산에서 `CodexMeter-1.3.0-beta.2.dmg`와 `CodexMeter-1.3.0-beta.2.dmg.sha256`를 같은 폴더에 내려받습니다. ZIP을 원하면 ZIP과 해당 `.zip.sha256` 파일을 선택합니다.
2. 내려받은 폴더에서 해당 체크섬을 확인합니다. `OK`가 아니면 설치하지 마세요.

   ```bash
   shasum -a 256 -c CodexMeter-1.3.0-beta.2.dmg.sha256
   ```

3. 실행 중인 CodexMeter를 메뉴의 **More → Quit**으로 종료합니다. DMG를 열어 `CodexMeter.app`을 Applications로 복사하고 기존 앱을 교체합니다. 베타와 정식 앱을 동시에 실행하지 마세요.
4. 이 앱은 **Apple Developer ID 서명·공증이 없는 ad-hoc 서명 빌드**입니다. 체크섬 확인 후 복사한 앱의 실행이 macOS에 의해 차단되는 경우에만 다음 앱 한정 명령을 실행합니다.

   ```bash
   xattr -dr com.apple.quarantine /Applications/CodexMeter.app
   open /Applications/CodexMeter.app
   ```

5. Settings → Information에서 **1.3.0-beta.2 (122)**를 확인하고 메뉴 상단에서 Codex와 Claude Code를 각각 선택해 표시가 바뀌는지 확인합니다.

체크섬은 내려받은 파일과 게시된 파일의 일치 여부를 확인합니다. Apple의 신뢰·공증을 의미하지 않습니다.

## 확인할 항목

- Codex ↔ Claude Code 전환 후 선택 강조, 서비스 이름과 사용량이 함께 바뀌는지
- 새 Claude Code 사용 후 Refresh 시 오늘의 토큰과 7D/30D 분석이 갱신되는지
- Usage / Projects / Sessions와 Settings가 선택한 서비스의 데이터를 보여주는지
- 문제가 있으면 버전, 선택한 서비스, 재현 동작과 개인정보를 가린 화면을 함께 알려 주세요.

## 데이터 및 되돌리기

이 베타는 정식 앱과 같은 번들 ID와 설정을 사용합니다. 기존 Codex DB는 유지하고 Claude 사용량은 별도 `Claude.sqlite`에 저장합니다. 원본 Codex/Claude 대화 로그나 로그인 파일은 릴리스 설치 과정에서 수정하지 않습니다. 단, 앱에서 직접 계정 전환·기록 초기화를 선택하면 해당 기능의 변경이 적용됩니다.

되돌리려면 베타를 종료하고 [정식 v1.2.0](https://github.com/HechoLP/CodexMeter/releases/tag/v1.2.0)의 검증된 앱으로 교체하세요. 기존 Codex 데이터는 그대로 사용하며, 이전 버전은 Claude DB를 읽지 않습니다. 별도 데이터 삭제는 필요하지 않습니다.

## 빌드 및 검증

- 소스: Claude 지원 PR #27의 검증된 커밋. 정확한 커밋은 릴리스의 `BUILD-INFO.txt`에 기록합니다.
- 전체 자동 테스트 261개 통과(실패 0, 환경 연동용 5개 제외). Universal 2 빌드와 ZIP·DMG의 앱 서명·버전·아키텍처·체크섬을 검사한 후 게시합니다.
- 실제 데스크톱 메뉴바 클릭과 VoiceOver 청취는 자동 테스트 범위와 구분합니다.

기본 정식 버전 설정을 변경하지 않고 이 태그에서 아래 환경 변수로 빌드합니다. 자동 업데이트 appcast는 생성하거나 게시하지 않습니다.

```bash
CODEXMETER_VERSION=1.3.0-beta.2 \
CODEXMETER_BUILD_NUMBER=122 \
CODEXMETER_REQUIRE_RELEASE_TAG=1 \
CODEXMETER_REQUIRE_PUBLIC_REPOSITORY=1 \
Scripts/release_unsigned.sh
```
