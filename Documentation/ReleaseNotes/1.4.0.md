# CodexMeter 1.4.0

CodexMeter 1.4.0 rebuilds the Settings window so Codex and Claude Code are configured side by side in one place.

## What changed

- **Sidebar-first Settings.** A tinted icon sidebar with a search field. It lists the shared sections — General, Menu Bar, Diagnostics, Information — and then a **Providers** group with **Codex** and **Claude Code**, each showing an on/off dot.
- **One window, not one per service.** Selecting a provider opens its own pane — account, limits, usage-analytics options, ChatGPT account totals (Codex), local-data status, and clear/rebuild. The window title tracks the selected section instead of naming a provider.
- **Flat rows.** Setting rows are a title with a short caption and a right-aligned control, separated by hairline dividers under small section headers — no boxed groups.

Everything the settings control is unchanged: the same preference keys, the same launch-at-login, update-check, history-clear, and Claude connect/disconnect behavior. Local accounting, privacy boundaries, and both databases are untouched from 1.3.1.

## Verification

- 283 automated tests, 0 failures (7 environment-integration tests skipped). New `SettingsLayoutTests` renders every settings pane in light and dark and asserts no horizontal clipping.
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later; the bundled Claude limits helper is signed and verified as part of the release.
- The app remains ad-hoc signed and not Apple-notarized. SHA-256 protects the first download; Sparkle authenticates later update feeds and archives with Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy HechoLP/tap/codexmeter
```

For a new installation:

```bash
brew install --cask HechoLP/tap/codexmeter
```

If macOS blocks this certificate-free app after installation, confirm that it came from `HechoLP/tap/codexmeter`, then remove quarantine from this app only:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-1.4.0.dmg` and `SHA256SUMS.txt` from this release into the same folder. Verify the checksum before opening the disk image:

```bash
cd ~/Downloads
grep ' CodexMeter-1.4.0.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-1.4.0.dmg
```

Only after the checksum reports `OK`, copy `CodexMeter.app` to Applications and use the app-scoped quarantine command above.
