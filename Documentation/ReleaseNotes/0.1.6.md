# CodexMeter 0.1.6

- Aligns Today, This Week, This Month, and All Time with the token-activity total displayed by the ChatGPT profile.
- Calculates the displayed total as `Input + Cached Input + Output` while keeping every component visible for auditing.
- Leaves the local database and Codex source logs unchanged; only the displayed total definition changes.

The raw Codex JSONL field named `total_tokens` equals input plus output. The ChatGPT profile activity figure also counts cached input as a separate component, so this release uses the profile-compatible definition for values labelled Total.

This build is ad-hoc signed and is not notarized by Apple. Homebrew verifies the exact published ZIP with SHA-256, but the personal Tap does not make the app Apple-trusted.

## Homebrew

```bash
brew upgrade --cask HechoLP/tap/codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

The `xattr` command removes macOS download quarantine from `CodexMeter.app` only. Run it only after the Homebrew installation completes from `HechoLP/tap/codexmeter`.

## Direct download

Download `CodexMeter-0.1.6.dmg` and `SHA256SUMS.txt` from the official public release into the same folder. Do not continue unless the checksum command prints `OK`.

```bash
cd ~/Downloads
grep ' CodexMeter-0.1.6.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-0.1.6.dmg
```

Copy `CodexMeter.app` from the DMG to `Applications`, then remove quarantine from that app and launch it:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```
