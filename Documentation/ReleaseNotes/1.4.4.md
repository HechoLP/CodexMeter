# CodexMeter 1.4.4

A copy and polish pass on the 1.4.x Settings redesign: less to read, and a nicer About pane.

## What changed

- **Trimmed Settings text.** Several notes repeated what an adjacent row or the clear-history confirmation dialog already said. The three "ChatGPT Account Totals" notes are now one, the two Claude footnotes are one, and the "This Mac Breakdown" note dropped its redundant first sentence and keeps only the fact that wasn't already on screen. A note about Diagnostics privacy that had drifted to the bottom of the Advanced pane, past an unrelated section, moved back next to Diagnostics where it belongs.
- **A native-style About pane.** The About pane now leads with the app icon, name, and version, centered, the way a standard macOS About panel does — replacing a one-line tagline sentence.
- **A little more breathing room.** Section spacing opened up slightly now that there is less text to separate.

No preference, control, or behavior changed.

## Verification

- 283 automated tests, 0 failures (7 environment-integration tests skipped).
- Every Settings pane re-rendered in light and dark mode and reviewed for clipping and text overflow.
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later; the bundled Claude limits helper is signed and verified as part of the release.
- The app remains ad-hoc signed and not Apple-notarized. SHA-256 protects the first download; Sparkle authenticates later update feeds and archives with Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy HechoLP/tap/codexmeter
```

For a new installation:

```bash
brew install --cask HechoLP/tap/codexmeter
```

If macOS blocks this certificate-free app after installation, confirm that it came from `HechoLP/tap/codexmeter`, then remove quarantine from this app only:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-1.4.4.dmg` and `SHA256SUMS.txt` from this release into the same folder. Verify the checksum before opening the disk image:

```bash
cd ~/Downloads
grep ' CodexMeter-1.4.4.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-1.4.4.dmg
```

Only after the checksum reports `OK`, copy `CodexMeter.app` to Applications and use the app-scoped quarantine command above.
