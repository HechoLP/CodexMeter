# CodexMeter 1.2.0

CodexMeter 1.2.0 separates token history from Codex limits and puts account switching directly in the menu bar.

## What changed

- **Token Usage / Codex Limits:** separate tabs, Weekly limits first, concise labels, and native hover and focus feedback.
- **Better-fitting detail views:** filters stay directly below the back header; charts and longer lists use the available content area without oversized blank space above them.
- **Account menu:** save the current login, add another account, manage saved logins, or choose an account without entering Settings.
- **Explicit switching:** CodexMeter asks before quitting and reopening Codex. It never rotates accounts based on quota or force-quits other clients.
- **Process detection:** unrelated terminal, browser-helper, and widget processes no longer incorrectly block a switch.

Existing local token history and counting rules are unchanged. Saved accounts use this Mac's non-synchronizing Keychain; credentials never enter the usage database or logs. Supported login locations and safeguards are described in [Accounts](https://github.com/HechoLP/CodexMeter/blob/v1.2.0/Documentation/ACCOUNTS.md).

## Verification and limitations

- Automated tests cover token accounting, account-switch ordering and failures, login-file protection, process detection, and synthetic native layouts.
- The package is Universal 2 for Apple silicon and Intel Macs running macOS 14 or later.
- **Not yet verified end to end:** a real two-account browser sign-in, Keychain permission prompt, and desktop restart/switch. Automated tests use synthetic credentials and do not change a running Codex login. Finish active work before switching; expired saved logins can require sign-in again.
- The app remains ad-hoc signed, without Apple Developer ID signing or notarization. SHA-256 protects the first download; Sparkle authenticates later update feeds and archives with Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy HechoLP/tap/codexmeter
```

For a new installation:

```bash
brew install --cask HechoLP/tap/codexmeter
```

Homebrew verifies the published ZIP checksum. If macOS blocks this certificate-free app after installation, confirm that it came from `HechoLP/tap/codexmeter`, then remove quarantine from this app only:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-1.2.0.dmg` and `SHA256SUMS.txt` from this release into the same folder. Verify the checksum before opening the disk image:

```bash
cd ~/Downloads
grep ' CodexMeter-1.2.0.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-1.2.0.dmg
```

Only after the checksum reports `OK`, copy `CodexMeter.app` to Applications and use the app-scoped quarantine command above. Do not run an unverified download or disable Gatekeeper globally.

## Recovery

This release does not migrate the usage database. Earlier signed release artifacts remain available if a manual rollback is needed. Do not delete the local usage database or saved Keychain entries when troubleshooting. Published version tags are immutable; corrections ship as a new patch release.
