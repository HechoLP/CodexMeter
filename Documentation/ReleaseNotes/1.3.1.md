# CodexMeter 1.3.1

A small follow-up to 1.3.0 that makes the Codex and Claude Code views read consistently and hardens Claude setup.

## What changed

- **Claude limit cards** no longer show the window name twice ("Weekly · Weekly"). Each card names its window once — "Weekly" or "5 hours" — the same way the Codex limit cards do.
- **Popover footer** now shows the same "Updated <relative>" freshness line for both services. When ChatGPT account totals are on, that snapshot's date stays in the Token History header rather than taking over the footer.
- **Claude usage keeps working** even if the status-line limits helper can't be installed. Local token totals connect anyway, and the Limits section explains the helper problem instead of the whole Claude integration going unavailable.

Local accounting, privacy boundaries, and the Codex database are unchanged from 1.3.0.

## Verification

- 279 automated tests, 0 failures (5 environment-integration tests skipped).
- Universal 2 build for Apple silicon and Intel Macs running macOS 14 or later; the bundled Claude limits helper is signed and verified as part of the release.
- The app remains ad-hoc signed and not Apple-notarized. SHA-256 protects the first download; Sparkle authenticates later update feeds and archives with Ed25519 signatures.

## Install or update with Homebrew

```bash
brew update
brew upgrade --cask --greedy HechoLP/tap/codexmeter
```

For a new installation:

```bash
brew install --cask HechoLP/tap/codexmeter
```

If macOS blocks this certificate-free app after installation, confirm that it came from `HechoLP/tap/codexmeter`, then remove quarantine from this app only:

```bash
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

## First direct-download launch

Download `CodexMeter-1.3.1.dmg` and `SHA256SUMS.txt` from this release into the same folder. Verify the checksum before opening the disk image:

```bash
cd ~/Downloads
grep ' CodexMeter-1.3.1.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
open CodexMeter-1.3.1.dmg
```

Only after the checksum reports `OK`, copy `CodexMeter.app` to Applications and use the app-scoped quarantine command above.
