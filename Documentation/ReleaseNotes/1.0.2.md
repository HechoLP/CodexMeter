# CodexMeter 1.0.2

CodexMeter 1.0.2 makes the macOS Settings experience easier to scan, navigate, and understand.

## Changes

- Settings now opens in a spacious, resizable window (980×680pt by default; 840×560pt minimum), so a category's controls are visible together instead of being constrained by the former compact window.
- A persistent sidebar lists every category with an icon, name, and purpose. It works with normal macOS keyboard navigation and exposes descriptive labels to VoiceOver.
- The selected category stays selected when the Settings window is reopened.
- The new **Information** category shows the installed version and build alongside local-data scope, privacy, updater, source, releases, and license links.

## Integrity and platform trust

These packages are distributed without Apple Developer ID, Apple notarization, or a Microsoft publisher certificate. Verify the official SHA-256 manifest before bypassing Gatekeeper or SmartScreen. The macOS automatic-update feed and ZIP archive are separately authenticated with Sparkle Ed25519 signatures.

## macOS with Homebrew

```bash
brew install --cask HechoLP/tap/codexmeter
xattr -dr com.apple.quarantine /Applications/CodexMeter.app
open /Applications/CodexMeter.app
```

Existing macOS installations can update through CodexMeter's signed update checker after the v1.0.2 feed is published.

## Windows portable download

Download the x64 or ARM64 ZIP together with `SHA256SUMS-windows.txt`, compare the PowerShell `Get-FileHash` result with the manifest, and extract the verified package to a permanent folder.
